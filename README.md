# Portfólio — Mariana Batista dos Santos

## Como usar
1. Extraia o ZIP para uma pasta.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.
4. Google Fonts e o gráfico Chart.js usam internet.

## Arquivos
- `index.html`: conteúdo das seções, navegação, imagens e links.
- `style.css`: fontes Dancing Script + Nunito, cores, layout, flores e responsividade.
- `script.js`: menu móvel, ano automático, gráfico e interação de cursor.
- `images/flor-holografica.png`: flor principal original do portfólio.
- `images/orquidea-holografica.png`: flor de fundo tipo orquídea.
- `images/cala-holografica.png`: flor de fundo tipo copo-de-leite/calla lily.

## Personalização importante
- Atualize a biografia e as habilidades para refletir seu nível real.
- Troque `seuemail@exemplo.com` e confirme os links sociais.
- Os cartões de projeto e os valores do gráfico são exemplos editáveis.
- As flores de fundo são intencionalmente discretas e não pulsam.
- O efeito de cursor funciona em mouse/trackpad e respeita a preferência de movimento reduzido.
