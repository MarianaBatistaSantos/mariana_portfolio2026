PROGRAMAÇÃO · PYTHON

Catálogo Botânico

Aplicação de terminal para cadastrar e organizar plantas, com nome popular, nome científico e histórico de alterações. O sistema permite incluir, listar, atualizar e remover registros, e valida as entradas do usuário para evitar erros. Desenvolvido na disciplina de Raciocínio Computacional (PUCPR), o projeto me ajudou a consolidar lógica de programação, funções, listas e dicionários.

PROGRAMAÇÃO · JAVA

Sistema de Financiamento de Imóveis

Sistema em Java que simula financiamentos de casas, apartamentos e terrenos, calculando a parcela mensal e o valor total de cada um. O projeto aplica conceitos de Programação Orientada a Objetos, como herança, polimorfismo e tratamento de exceções, além de validação de dados e gravação em arquivo (texto e serialização). O código é organizado em pacotes separados, o que facilitou a manutenção e a leitura..
